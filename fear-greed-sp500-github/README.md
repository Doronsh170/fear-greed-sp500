# פחד ותאוות בצע מול S&P 500

ויזואליזציה אינטראקטיבית בעברית של תשואות עתידיות ממוצעות לפי סנטימנט השוק ביום הבסיס.

## מה כלול

- גרף תשואות עם בחירה בין חודש, 3 חודשים, 6 חודשים ושנה.
- טבלת חום עם כל 20 הממוצעים והדגשת הטווח הנבחר.
- התפלגות 3,832 ימי מסחר בין חמש קבוצות סנטימנט.
- התאמה לנייד, עברית מימין לשמאל והדפסה או שמירה כ־PDF.
- אתר סטטי ללא התקנה, תהליך בנייה, ספריות חיצוניות או מפתחות גישה.

## העלאה ל־GitHub

1. צרו מאגר, למשל `fear-greed-sp500`.
2. חלצו את קובץ ה־ZIP והעלו את **תוכן התיקייה** לשורש המאגר. `index.html` צריך להופיע בשורש, ולצדו תיקיית `assets`.
3. שמרו את השינויים בענף `main`.
4. עברו אל **Settings → Pages**.
5. תחת **Build and deployment → Source** בחרו **Deploy from a branch**.
6. בחרו בענף `main` ובתיקייה **/(root)** ולחצו **Save**.
7. לאחר סיום הפרסום, כתובת האתר תופיע בעמוד Pages.

מבנה הכתובת במאגר רגיל: `https://YOUR-USERNAME.github.io/fear-greed-sp500/`.

הפעלת Pages דורשת הרשאה מתאימה במאגר. הזמינות למאגרים פרטיים תלויה בתוכנית GitHub.

[הוראות GitHub הרשמיות לפרסום](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## צפייה מקומית

פתחו את `index.html` בדפדפן. אין צורך בשרת או בחיבור לאינטרנט.

## קבצים

```text
index.html          מבנה העמוד
assets/styles.css   עיצוב, התאמה לנייד והדפסה
assets/app.js       הנתונים והאינטראקציות
.nojekyll           פרסום סטטי ללא עיבוד Jekyll
```

## הנתונים

הערכים הועתקו מהוויזואליזציה המקורית שסופקה; הם לא חושבו מחדש מקובצי האקסל. תקופת המדגם ושיטת חישוב התשואות לא פורטו במקור. הגרפים מציגים ממוצעים ואינם מציגים את פיזור התוצאות.

לעריכת הערכים, עדכנו את מערך `groups` בקובץ `assets/app.js`. סכום ספירות הימים הוא 3,832. אם משנים את ספירות הימים או את טווח הנתונים, יש לעדכן גם את סך הימים, הטקסטים המסכמים ואת סולם הגרף לפי הצורך.

מקורות כפי שצוינו בקובץ המקורי: Investing.com ו־FinHacker.

נערך ע״י דורון שרייבמן.
